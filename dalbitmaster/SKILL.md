# Add missing Dalbit products to the Product Master

## Sources and scope

- Product photos: `C:\Users\sshoo\Dalbit`. Each immediate child folder named like a SKU (for example `b33`, `b01blue`, or `t05`) is a product candidate. Ignore non-SKU folders such as `Stone Cards` and loose shared graphics. Do not infer a new SKU from a photograph or filename.
- Live master: [Dalbit_Product_Master](https://docs.google.com/spreadsheets/d/194QEkWHyWEDdsgV_nMvJk_IGOhl4ZsZ2L4TwpJ7NLUE/edit). Resolve its current tab, headers, data, and validation from a fresh read each run. Never rely on saved row numbers or an older export.
- Brand and cultural reference: [dalbitbrand.md](C:/Users/sshoo/OneDrive/Documents/ChatGPT/Dalbit/dalbitbrand.md). Read it when identifying a meaningful piece or writing a cultural connection; the live Master and the owner's current directions remain authoritative for product-specific facts and labels.
- This skill may create rows for genuinely missing SKUs in that master. It does not publish Etsy listings or edit other files or databases.

## Workflow

1. Inventory SKU-named product folders with usable product photos. Read the live master's metadata and SKU column across its populated rows. Match SKU strings case-insensitively after trimming whitespace, retaining the folder's actual SKU spelling for a new row. A SKU already present anywhere in the master is **not missing**, even if its row is incomplete. Report incomplete existing rows separately; do not duplicate or silently edit them. If the master has duplicate matching SKUs, resolve that conflict before writing for that SKU.
2. For each missing SKU, inspect multiple clear photos when available. Identify the product type, visible components, colors, fastening, and recognizable motifs. Compare several current, similar product rows and reuse their established product-name pattern, descriptive keywords, material wording, color format, and Korean design-element terminology wherever each term is accurate for this product. Use the SKU's own photos for its facts; comparable rows supply wording and structure, not evidence that it has the same materials or motif.
   For each bracelet, review its meaningful decorative piece or pieces, such as a focal charm, stone, bead, or pendant; do not assign symbolism to incidental hardware or every bead. Describe each focal piece's visible shape and details, then suggest a motif name. Treat the user's correction or chosen name as the final product label. Research any claimed Korean cultural connection using reliable museum or cultural sources. Distinguish documented traditional symbolism from a modern Dalbit interpretation; flag an unclear motif, material, or species briefly, and never invent symbolism or claim a motif is uniquely Korean. Prepare this concise copy for each meaningful element in the row and later cultural card:
   `Korean Cultural Element — [English name] ([Korean name])`
   Follow it with one warm, natural English sentence explaining the supported cultural connection. Store the chosen motif label or labels in the master's `Korean design element/inspiration` field and the sentence, source, and uncertainty in `Source / notes` when those fields support it. Do not force a researched meaning when the available evidence only establishes a visual motif.
3. Ask the user in **one grouped request** for the size and retail price of each missing SKU. Show each SKU and identified product type so the answers are easy to map. Request size in inches (length or length range, with the measurement type if relevant) and retail price in USD; allow the user to say size is not applicable for a product type. Do not guess these from photos or neighboring products. If the user supplies values for only some SKUs, proceed with those complete SKUs and keep the others pending. A prior answer in the conversation counts; do not ask again for a value already supplied clearly.
4. Draft the new row using the master's live column headings. For `Product name`, use the existing naming style and the product's most distinctive supported features. For `Materials`, use specific composition such as jade, freshwater pearl, crystal, or gold plating only when confirmed by reliable product-specific evidence; an image alone usually supports descriptive terms such as green beads, pearl-like beads, or gold-tone hardware. For `Color`, describe the visible palette in the master's brief style. For `Korean design element/inspiration`, name a recognizable motif only when the photo or product-specific evidence supports that identification. Do not convert a generic flower, pouch, or color palette into an asserted Korean symbol. Leave a genuinely unknown field blank and record the uncertainty in `Source / notes` instead of inventing a fact.
5. Put the user's applicable size in `Length range (inches)`, following the comparable rows' measurement convention; leave it blank when the user confirms size does not apply. Put the user's retail price in `Retail price (USD)`, preserving the supplied meaning and using the sheet's existing number/currency conventions. Fill `Fit / fastening` only when visible or confirmed. Use the master's available unpublished status value for `Record status`; if there is no defined value, use `Unlisted`. Leave unit cost, inventory, and optimization fields blank unless separately supplied or verified. In `Source / notes`, identify the local photo folder and briefly state any material or motif uncertainty.
6. Immediately before writing, re-read the current SKU column and destination row structure so a concurrent change cannot create a duplicate. Add each complete missing SKU once in its appropriate section, preserving headers, existing rows, formulas, formatting, and validation. Use the connected Google Sheets edit workflow for native row insertion and read back every new row. If a SKU appears in the master during the recheck, skip it and report it.
7. Report which SKUs were added, which were already present (including incomplete rows), and which still need size, price, or source clarification. Do not claim an uncertain visual identification as confirmed.

The user's request to run this skill authorizes adding the completed missing-product rows after they provide size and price. No separate review gate is needed unless the user asks for one.
